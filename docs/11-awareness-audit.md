# 15 · Awareness audit (Schwartz gate)

**When:** after wave 2, before the build sheet. **Time:** 30 minutes plus one render batch. **Output:** a five-row table and wave 3.

Map every static to one stage: unaware, problem aware, solution aware, product aware, most aware. Slates built from a landing page always stack in the middle three. This gate forces the ends.

| Stage | What the cell does | Rules |
|---|---|---|
| Unaware | Education or curiosity in the category, no offer | no price on image, Learn More, own ad set |
| Problem aware | Names the felt problem before the treatment is on the table (the workaround she does every morning, the permission she needs, the decision she cannot make) | no price, Learn More, own ad set |
| Solution aware | Why this version of the treatment | offer statics, main ad set |
| Product aware | Why this practice and provider | offer statics, main ad set |
| Most aware | Retargeting only: how the visit goes, your spot is still open, reviews | Book Now, warm audiences only, never cold |

## Steps
1. Fill the table with the current slate. Count per row.
2. Any row with fewer than two cells gets built now (usually unaware, problem aware, most aware).
3. Unaware and problem-aware cells go into a separate prospecting ad set with a soft CTA. Mixed into the offer set they inflate CPL and get starved.
4. Retargeting cells go into their own set with the warm audiences and exclusions.

## Gate
Every stage has at least two cells. The build sheet lists which ad set each cell belongs to.
