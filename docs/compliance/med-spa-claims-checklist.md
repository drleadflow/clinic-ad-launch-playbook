# Med-spa claims checklist

Run this on every headline, bullet, primary text and landing page before the owner sees it.

**Device and indication**
- [ ] "FDA-cleared" only with the 510(k) on file AND only for the cleared indication. A lipolysis clearance is not a skin-tightening clearance. Describe the mechanism instead of claiming an indication.
- [ ] No "permanent", "melt", "erase", "removal", "lose X inches", "safe for all skin types", "minimal risk".
- [ ] Off-label uses are physician-performed, consented, and never the headline.
- [ ] No trademarked treatment names you do not licence (a competitor's brand name is not a generic).

**Results**
- [ ] No before/after unless consented, unretouched and typical. Implied before/after (rough then smooth) counts.
- [ ] "Individual results vary" where a result is shown.
- [ ] Recovery, session count and course length stated honestly or not at all.

**Money**
- [ ] Any monthly figure needs the example amount, term and APR together (Regulation Z triggering terms).
- [ ] Deposit wording exactly as the practice operates it (refundable, credited).
- [ ] Prices only where the practice has published or approved them in writing.

**Privacy**
- [ ] Lead form collects name, email, phone, consent and nothing clinical unless a BAA exists with the CRM.
- [ ] No treatment name in the pixel URL, event payload or UTM (hospital-pixel settlement pattern).

**Skin of colour**
- [ ] Pigment risk named where the audience is Fitzpatrick IV to VI; never "no risk".
- [ ] No melasma claim for ablative devices.

**Voice**
- [ ] Credentials exactly as the bios read. Zero em dashes. No invented facts.
